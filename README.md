# LibraryManager

**LibraryManager** é um sistema simples de gestão de livros desenvolvido em **Java** como um exercício prático para melhorar as habilidades em Programção Orientada a Objetos (POO). O sistema utiliza conceitos fundamentais de POO, como classes, herança e encapsulamento, e também explora o uso de **generics** por meio da classe `ArrayList`.

---

## 📂 Estrutura do Projeto

O sistema é composto pelas seguintes classes:

- **Main**: Classe principal que inicializa e executa o sistema.
- **User**: Representa um usuário da biblioteca, armazenando informações como nome e ID.
- **Loan**: Gerencia os empréstimos de livros, vinculando usuários aos livros emprestados.
- **Book**: Representa os livros da biblioteca, com informações como título, autor e categoria.
- **Category**: Define categorias para organizar os livros (por exemplo, ficção, não-ficção, ciência).
- **Library**: Classe central que gerencia a coleção de livros, usuários e empréstimos.

---

## 🔧 Tecnologias e Conceitos Utilizados

- **Java**: Linguagem de programação principal.
- **POO (Programação Orientada a Objetos)**:
  - Classes e objetos.
  - Encapsulamento.
  - Herança e composição.
- **Generics**: Uso de `ArrayList` para armazenar coleções dinâmicas de objetos.

## 🚀 Como Executar

1. Certifique-se de ter o **JDK** instalado em seu computador.
2. Clone o repositório:

```bash
git clone https://github.com/MarceloHabreu/LibraryManager.git
```

3. Navegue até o diretório do projeto e compile os arquivos Java:

```bash
javac *.java
```

4. Execute a classe principal:

```bash
java Main
```

---

## 🌟 Funcionalidades

- Adicionar e gerenciar livros na biblioteca.
- Criar e gerenciar usuários.
- Realizar empréstimos e devoluções de livros.
- Organizar livros por categorias.
